# Xin Zhang · 张欣

Academic homepage: https://zephipage.github.io/

This repository contains a static website published with GitHub Pages from `main` at the repository root.

- `index.html`: profile, experience, education, and academic service
- `styles.css`: layout and appearance
- `app.js`: language, theme, portrait, and publication interactions
- `publications.js`: publication data
- `assets/`: portraits, research images, CV, and image credits

No package installation or build step is required. Keep `.nojekyll` in the repository root.
